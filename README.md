# portal-cn-notes

本仓库用于归档和发布多个独立的 HTML 页面。这些页面以静态形式存放，不依赖特定后端服务，可直接通过浏览器打开或部署至任意静态托管平台。

## 项目简介

本项目是一个轻量级的页面归档仓库，旨在收集和组织一批自包含的 HTML 文件。每个页面独立存在，互不依赖，适合用于信息展示、工具页面或临时内容发布。仓库本身不绑定任何具体域名或网站，仅为存储与分发提供便利。

## 目录说明

```
portal-cn-notes/
├── pages/          # 存放所有 HTML 页面文件
├── assets/         # 页面引用的资源文件（如 CSS、JS、图片等）
└── README.md       # 本文件
```

- `pages/`：每个 HTML 文件为一个独立页面，命名清晰，便于识别。
- `assets/`：按需存放页面所需的静态资源，保持目录结构简洁。

## 页面归档说明

- 所有页面均为静态 HTML，无动态数据加载。
- 页面之间无链接跳转或依赖关系，可单独使用。
- 归档内容以信息记录和工具展示为主，不包含任何商业推广或诱导性内容。
- 页面内容在归档时已做基本检查，但使用者应自行确认其适用性。

## 维护说明

- 本仓库由维护者不定期更新，新增或修改页面将直接提交至 `main` 分支。
- 如发现页面显示异常或内容错误，欢迎提交 Issue 反馈。
- 不接受涉及敏感、违法或侵犯他人权益的内容提交。
- 仓库保持开放，但不对页面内容的外部使用后果负责。

## 使用方式

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/your-username/portal-cn-notes.git
   ```
2. 直接在浏览器中打开 `pages/` 目录下的 HTML 文件。
3. 或将整个仓库部署至任何静态托管服务（如 GitHub Pages、Netlify 等）。
